이 페이지는 두 가지 연결 방식을 지원합니다. Chrome의 Local Network Access 직접 연결이 실패하면, 버튼 클릭으로 localhost 브리지를 팝업으로 열어 결과를 되돌려 받습니다.

연결 전입니다.

팝업 방식은 GitHub Pages → localhost의 cross-origin fetch를 사용하지 않습니다. 사용자 클릭으로 http://127.0.0.1:17891/relay를 연 뒤, 로컬 브리지가 get_music_scores를 실행하고 postMessage로 결과만 이 페이지에 돌려줍니다.
