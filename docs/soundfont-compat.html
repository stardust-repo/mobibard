SF3 / DLS를 모비바드 호환으로 만들기

모비바드는 "호환 표시"가 있는 음색 파일만 자체 악기 배치(프리셋 0~14)로 재생합니다. 표시가 없는 파일은 일반 GM 방식(프로그램 번호 = 프리셋 번호)으로 읽어서, 악기가 엉뚱하게 나옵니다.

1. 호환 표시 넣기

파일의 RIFF INFO 목록 안 ICMT(Comment)에 아래 두 줄을 넣습니다.

MobiBard-Compatible: 1
MobiBard-Version: v1.0

SF2/SF3는 Polyphone·Swami 등의 "Comments" 항목, DLS는 Gigasampler/DLS 편집기의 Comments에 입력하면 됩니다. 편집기가 마땅치 않으면 add_mobibard_marker.py로 샘플·프리셋은 그대로 두고 표시만 추가할 수 있습니다.

python add_mobibard_marker.py 원본.dls 결과.dls

2. 프리셋 배치 (Bank 0)

번호악기번호악기
0Piano (기본/대체)8Music Box
1Chalumeau9Guitar
2Flute10Harmonica
3Harp11Cat (보컬)
4Lute12Big Drum
5Mandolin13Cymbals
6Violin14Gramophone
7Xylophone

MIDI의 프로그램/드럼 노트는 모비바드가 위 프리셋으로 변환합니다. 파일에는 프리셋 번호만 맞춰 두면 됩니다. 없는 번호는 0번(Piano)으로 대체됩니다.

3. 소리 설정 팁

  • 엔벌로프(A/D/S/R)는 파일 값을 그대로 따릅니다. SF2/SF3는 Generator 34·36·37·38, DLS는 Articulation(EG1) 값입니다.
  • 길게 울리는 악기는 샘플에 루프를 넣고 Release를 충분히 주세요. 루프가 없으면 샘플 길이만큼만 납니다.
  • 타악기(Cat, Big Drum, Cymbals)는 Sustain 0 + 긴 Release로 한 번 치면 끝까지 울리게 하는 편이 자연스럽습니다.

4. 확인

파일을 불러온 뒤 사운드폰트 이름이 바뀌고, 곡의 각 채널이 기본 음색과 같은 악기로 나오면 정상입니다.

5. 표시 없이 시도하기

호환 표시가 없어도 파일 이름에 mobibard가 들어 있으면, 불러올 때 "모비바드 호환으로 시도할까요?"라고 물어봅니다. 승인하면 위 배치로 읽어 봅니다. 번호가 맞게 만들어진 파일이면 이것만으로도 동작하지만, 확실하게 쓰려면 1번처럼 표시를 넣는 쪽이 좋습니다. 이미 표시가 있는 파일은 묻지 않습니다.

Making an SF3 / DLS MobiBard-compatible

MobiBard only uses its own instrument layout (presets 0–14) for banks that carry a compatibility marker. Without it the file is read as plain GM (program number = preset number), so instruments come out wrong.

1. Add the marker

Put these two lines in the ICMT (Comment) entry of the file's RIFF INFO list:

MobiBard-Compatible: 1
MobiBard-Version: v1.0

Use the "Comments" field in Polyphone/Swami (SF2/SF3) or a DLS editor. Or run add_mobibard_marker.py, which only adds the marker and leaves samples and presets untouched.

python add_mobibard_marker.py input.dls output.dls

2. Preset layout (Bank 0)

#Instrument#Instrument
0Piano (default/fallback)8Music Box
1Chalumeau9Guitar
2Flute10Harmonica
3Harp11Cat (vocal)
4Lute12Big Drum
5Mandolin13Cymbals
6Violin14Gramophone
7Xylophone

MobiBard converts MIDI programs and drum notes to these presets itself; just keep the preset numbers. Missing numbers fall back to preset 0 (Piano).

3. Sound tips

  • Envelopes (A/D/S/R) are taken from the file: SF2/SF3 generators 34/36/37/38, DLS articulation (EG1).
  • Sustained instruments need a sample loop and a decent Release; without a loop the sound ends with the sample.
  • For percussion (Cat, Big Drum, Cymbals) use Sustain 0 with a long Release so one hit rings out.

4. Check

After loading, the soundfont name changes and every channel should use the same instruments as with the default sound.

5. Trying without the marker

Even without the marker, if the file name contains mobibard, loading it asks whether to try MobiBard-compatible mode. If you accept, the file is read with the layout above. This works when the preset numbers already match, but adding the marker (step 1) is the reliable way. Files that already carry the marker are not asked.

SF3 / DLS をモビバード互換にする方法

モビバードは「互換マーカー」のある音色ファイルだけ独自の楽器配置(プリセット0〜14)で再生します。マーカーがないと通常のGM方式(プログラム番号=プリセット番号)で読むため、楽器が違って聞こえます。

1. マーカーを入れる

RIFF INFO リストの ICMT(コメント)に次の2行を入れます。

MobiBard-Compatible: 1
MobiBard-Version: v1.0

Polyphone/Swami(SF2/SF3)やDLSエディタの「Comments」欄に入力します。add_mobibard_marker.py を使うと、サンプルやプリセットはそのままマーカーだけ追加できます。

python add_mobibard_marker.py input.dls output.dls

2. プリセット配置(Bank 0)

No.楽器No.楽器
0Piano(既定/代替)8Music Box
1Chalumeau9Guitar
2Flute10Harmonica
3Harp11Cat(ボーカル)
4Lute12Big Drum
5Mandolin13Cymbals
6Violin14Gramophone
7Xylophone

MIDIのプログラム/ドラムノートはモビバードが上記プリセットへ変換します。番号さえ合わせればOKです。無い番号は0(Piano)になります。

3. 音作りのヒント

  • エンベロープ(A/D/S/R)はファイルの値に従います。SF2/SF3はGenerator 34/36/37/38、DLSはArticulation(EG1)です。
  • 伸びる楽器はサンプルにループと十分なReleaseを設定してください。ループがないとサンプル長で終わります。
  • 打楽器(Cat, Big Drum, Cymbals)はSustain 0と長いReleaseで鳴り切らせると自然です。

4. 確認

読み込み後、サウンドフォント名が変わり、各チャンネルが既定音色と同じ楽器で鳴れば正常です。

5. マーカーなしで試す

マーカーがなくても、ファイル名に mobibard が含まれていれば、読み込み時に「モビバード互換で試しますか?」と確認します。承認すると上の配置で読み込みます。番号が合っていればこれだけで動きますが、確実に使うには手順1のマーカーを入れてください。マーカー付きのファイルでは確認しません。

让 SF3 / DLS 兼容 MobiBard

只有带"兼容标记"的音色文件，MobiBard 才会使用自己的乐器布局(预设 0–14)。没有标记时按普通 GM 方式(程序号=预设号)读取，乐器会不对。

1. 添加标记

在文件 RIFF INFO 列表的 ICMT(注释)中写入以下两行：

MobiBard-Compatible: 1
MobiBard-Version: v1.0

可在 Polyphone/Swami(SF2/SF3)或 DLS 编辑器的"Comments"中填写；也可用 add_mobibard_marker.py，只添加标记，不改动采样和预设。

python add_mobibard_marker.py input.dls output.dls

2. 预设布局 (Bank 0)

编号乐器编号乐器
0Piano(默认/回退)8Music Box
1Chalumeau9Guitar
2Flute10Harmonica
3Harp11Cat(人声)
4Lute12Big Drum
5Mandolin13Cymbals
6Violin14Gramophone
7Xylophone

MIDI 的程序号/鼓音符由 MobiBard 自行转换为上述预设，只需保证预设编号一致。缺失的编号回退到 0(Piano)。

3. 音色提示

  • 包络(A/D/S/R)遵循文件中的值：SF2/SF3 为 Generator 34/36/37/38，DLS 为 Articulation(EG1)。
  • 延音乐器需要采样循环和足够的 Release；没有循环则随采样结束。
  • 打击乐(Cat, Big Drum, Cymbals)建议 Sustain 0 加较长 Release，使单次敲击能完整响完。

4. 检查

加载后音色文件名会改变，各声道应与默认音色使用相同的乐器。

5. 无标记时的尝试

即使没有标记，只要文件名包含 mobibard，加载时会询问是否尝试 MobiBard 兼容模式。确认后按上述布局读取。预设编号本来就对应时可直接使用，但想稳妥建议按第 1 步添加标记。已带标记的文件不会询问。

讓 SF3 / DLS 相容 MobiBard

只有帶「相容標記」的音色檔，MobiBard 才會使用自己的樂器配置(預設 0–14)。沒有標記時依一般 GM 方式(程式號=預設號)讀取，樂器會不對。

1. 加入標記

在檔案 RIFF INFO 清單的 ICMT(註解)中寫入以下兩行：

MobiBard-Compatible: 1
MobiBard-Version: v1.0

可在 Polyphone/Swami(SF2/SF3)或 DLS 編輯器的「Comments」填寫；也可使用 add_mobibard_marker.py，只加入標記，不更動取樣與預設。

python add_mobibard_marker.py input.dls output.dls

2. 預設配置 (Bank 0)

編號樂器編號樂器
0Piano(預設/備援)8Music Box
1Chalumeau9Guitar
2Flute10Harmonica
3Harp11Cat(人聲)
4Lute12Big Drum
5Mandolin13Cymbals
6Violin14Gramophone
7Xylophone

MIDI 的程式號/鼓音符由 MobiBard 自行轉換為上述預設，只需讓預設編號一致。缺少的編號會退回 0(Piano)。

3. 音色提示

  • 包絡(A/D/S/R)依檔案中的值：SF2/SF3 為 Generator 34/36/37/38，DLS 為 Articulation(EG1)。
  • 延音樂器需要取樣迴圈與足夠的 Release；沒有迴圈則隨取樣結束。
  • 打擊樂(Cat, Big Drum, Cymbals)建議 Sustain 0 搭配較長 Release，讓單次敲擊完整響完。

4. 檢查

載入後音色檔名稱會改變，各聲道應與預設音色使用相同的樂器。

5. 沒有標記時的嘗試

即使沒有標記，只要檔名包含 mobibard，載入時會詢問是否嘗試 MobiBard 相容模式。確認後依上述配置讀取。預設編號本來就對應時可直接使用，但想穩妥建議依第 1 步加入標記。已帶標記的檔案不會詢問。
