MML 코드 도움말

    
재생기에서 지원하는 기본 MML 코드입니다. 대소문자는 구분하지 않습니다. 숫자가 붙는 코드는 아래 설명의 범위 안에서 사용해 주세요.

    

      
코드설명예시

      
MML@...;전체 악보 형식입니다. @ 뒤 내용을 쉼표로 나눠 최대 6채널(멜로디, 화음1~5)을 입력하고 ;로 끝냅니다.MML@cde,egc,ccg;

      
T32~255템포(BPM)입니다. 숫자가 클수록 빠릅니다.T120

      
O0~7옥타브입니다. 숫자가 클수록 높은 음역입니다.O4cde

      
L1,2,4,8,16,32,64기본 음 길이입니다. 숫자는 “몇 분음표인지”를 뜻합니다. L4는 4분음표, L8은 8분음표라서 숫자가 클수록 짧아집니다.L8cdef

      
V0~15볼륨입니다. 0은 가장 작고 15가 가장 큽니다.V12cde

      
c d e f g a b도레미파솔라시 음표입니다. 뒤에 1,2,4,8,16,32,64를 붙이면 그 음표만 길이를 바꿉니다.c4 d8 e

      
r쉼표입니다. 뒤 숫자는 쉼표 길이입니다.r4 r8

      
N4~88마비노기 음 번호로 음 높이를 직접 지정합니다. 숫자가 클수록 높은 음입니다. N48은 4옥타브 도입니다.L8N48N52

      
# + -반음 올림/내림입니다. #, +는 반음 올림, -는 반음 내림입니다.c# d-

      
< >옥타브를 한 단계 이동합니다. >는 한 옥타브 위로, <는 한 옥타브 아래로 이동합니다.>c<c

      
.점음표입니다. 바로 앞 길이를 1.5배로 늘립니다. 점을 여러 개 붙이면 남은 절반씩 더 늘어납니다.c4. r8.

      
&같은 음을 이어서 길게 연주합니다. & 앞뒤는 같은 음이어야 합니다.c4&c8

    

    

      짧은 예시
      MML@T120V12O5L8cdefgab>c,O4V10L4ceg,O3V9L2cgcg;

MIDI 추출

      BETA
    


    

      MuScriptor의 오디오→MIDI 변환 AI 모델을 컴퓨터에 보다 쉽게 설치하고 실행할 수 있도록 준비한 보조 패키지를 제공합니다. 오디오 파일을 입력하면 AI가 연주 내용을 분석해 MIDI 파일로 변환합니다.
    


    

      
        Windows
        Windows용 패키지 받기
        설치·실행용 BAT 파일 포함
      
      
        macOS
        macOS용 패키지 받기
        설치·실행용 SH 파일 포함
      
    


    

      

        
변환 예시

        아래 샘플은 재생 버튼을 누른 뒤에만 다운로드됩니다.
      


      

        
        
      


      

        

          

            입력 오디오
            변환에 사용한 원본 · sample_in.mp3
          

          
          
          
재생 버튼을 누르면 오디오 파일을 불러옵니다.

        


        

          

            출력 MIDI
            AI가 변환한 결과 · sample_out.mid
          

          
          
          
재생 버튼을 누르면 sample_out.mid의 미리듣기 오디오를 불러옵니다.

        

      

    


    

      

        권장 대상
        Python 설치나 로컬 AI 모델 실행 경험이 있는 사용자에게 권장합니다. 처음 실행할 때 모델 다운로드와 환경 설정이 필요하며, PC 사양과 원본 오디오에 따라 처리 시간과 변환 결과가 달라질 수 있습니다.
      

      
필수 준비

      
    
        
  • Python 3.10 이상 — Python 3.12 또는 3.13 64비트를 권장합니다. 설치 후 Windows에서는 python --version, macOS에서는 python3 --version 명령이 실행되어야 합니다.
    • 
        
  • Hugging Face 계정 — AI 모델을 내려받기 위해 필요합니다. 사용할 모델 페이지에서 로그인한 뒤 이용 조건에 동의하세요.
    • 
        
  • 인터넷 연결과 저장 공간 — 첫 설치와 모델 다운로드에 필요합니다. AI 모델 파일은 이 패키지에 포함되어 있지 않습니다.
    • 
      

      
GPU는 선택 사항: GPU가 없어도 CPU로 실행할 수 있지만 변환 시간이 길어질 수 있습니다. Windows는 NVIDIA CUDA를 우선 사용하며, Apple Silicon Mac은 macOS 14 이상에서 MLX 가속을 사용할 수 있습니다. Intel Mac은 CPU로 실행됩니다.

    


    

      설치 방법·설정·악기 목록 자세히 보기
      

        

          
빠른 설치

          

            

              Windows
              
    
                
  1. Python 3.12 또는 3.13 64비트를 설치하고, 설치 화면에서 Add python.exe to PATH를 선택합니다.
    2. 
                
  2. 압축을 푼 뒤 1_install.bat를 실행합니다.
    3. 
                
  3. 설치가 끝나면 2_model_run.bat를 실행합니다. 필요한 경우 실행 전에 settings.toml을 수정합니다.
    4. 
              

            

            

              macOS
              
    
                
  1. Python 3.12 또는 3.13을 설치한 뒤 Terminal에서 압축을 푼 폴더로 이동합니다.
    2. 
                
  2. bash ./1_install.sh를 실행합니다.
    3. 
                
  3. bash ./2_model_run.sh를 실행합니다.
    4. 
              

            

          

          
서버가 시작되면 브라우저가 자동으로 열립니다. 열리지 않으면 http://127.0.0.1:8222/에 접속하세요. 처음 실행할 때는 Hugging Face 로그인과 모델 다운로드 안내가 표시될 수 있습니다.

        


        

          
설정 파일 요약

          
    
            
  • name: small / medium / large 중 모델 크기를 선택합니다. 처음에는 small 또는 medium을 권장합니다.
    • 
            
  • quantization: fp16은 기본 권장, q8은 메모리 절약, fp32는 더 많은 메모리를 사용하는 방식입니다.
    • 
            
  • use_gpu: 가능한 경우 GPU 가속을 사용합니다. batch_size는 한 번에 처리할 분량을 정합니다.
    • 
            
  • instruments: 예상 악기를 직접 지정합니다. 빈 배열 []로 두면 AI가 자동으로 판단합니다.
    • 
          

          
메모리가 부족하거나 실행이 멈추면 batch_size를 1~2로 낮추고, medium 또는 large 대신 small 모델을 사용하세요.

        


        

          
악기 목록과 포함 문서

          
INSTRUMENT_LIST_KO.txt에서 AI가 인식할 수 있는 악기 이름과 설정 예시를 확인할 수 있습니다. 어떤 악기가 들어 있는지 확실하지 않다면 instruments = []를 그대로 두어 자동 판단을 사용하세요.

          
패키지에는 빠른 사용법(QUICK_START_KO.txt), 설정 파일(settings.toml), 악기 목록, 기술 설명, 라이선스 안내와 설치·실행 스크립트가 포함되어 있습니다.

        


        

          
모델 이용 전 확인

          
이 패키지는 MuScriptor의 공식 배포본이 아니라 설치와 실행을 돕기 위해 구성한 보조 패키지입니다. MuScriptor 프로그램 코드와 AI 모델에는 서로 다른 라이선스가 적용됩니다. 모델은 Hugging Face에서 본인 계정으로 이용 조건에 동의한 뒤 내려받으며, 저작권을 보유했거나 변환 허가를 받은 오디오만 사용하세요.

MIDI 변환 설정

    

      
MML 채널별 역할, 겹침 병합 방식, 사용할 악기를 선택해 주세요.

    

    

      
        이 창은 MIDI 파일의 악기들을 마비노기 MML 최대 6채널로 나눠 넣는 설정입니다.
        설명 접기/펼치기
      
      

        
    
          
  1. 연주 듣기로 원본 파일이 어떤 곡인지 먼저 확인합니다.
    2. 
          
  2. 각 MML 채널마다 악기를 선택할 수 있습니다. 왼쪽에서 채널을 고른 뒤, 오른쪽에서 배정할 악기를 선택합니다.
    3. 
          
  3. 악기를 하나 이상 선택한 채널만 최종 MML에 포함됩니다. 최대 6채널까지 사용할 수 있습니다.
    4. 
          
  4. 미리 듣기로 현재 설정을 MML로 바꿨을 때의 소리를 먼저 확인하고, 변환을 누르면 현재 MML 편집기에 반영됩니다.
    5. 
        

        

          자동: 선택한 악기를 가능한 범위에서 자동 배치
          고음: 높은 음역을 우선 배치
          저음: 낮은 음역을 우선 배치
          생성: 선택한 선율에서 코드와 아르페지오 반주를 생성
          비트: 드럼/타악 계열만 배치
          겹침 병합: MML 6채널 한계 안에 더 많은 소리를 담기 위해, 이미 울리는 음 일부를 줄이고 겹친 음을 이어 넣습니다.
        

      

    


    

      

        

          MML 채널
          각 MML 채널마다 악기를 선택할 수 있습니다.
        

        

          
비트 악기 정보를 확인하는 중입니다.
