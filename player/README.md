# Player 구현 스펙 스냅샷

마지막 갱신: 2026-08-23 KST  
출시 기준: 이 README와 현재 배포 소스

## 목적

여러 연주 파일을 최대 6개 마비노기 MML 채널로 변환하고, 원본과 현재 옵션 조합의 결과를 피아노롤/재생으로 확인한 뒤 복사·저장하는 상세 생성기입니다.

## 계산 원칙

```text
불러온 원본 + 악기/채널 배정 + 공용 옵션 + 채널 옵션 → 현재 결과 MML
```

옵션은 직전 결과에 누적하지 않습니다. 같은 입력/옵션 서명은 가능한 한 재계산을 생략합니다.

## 새 파일/붙여넣기

- 로컬, Google Drive, 붙여넣기로 새 소스를 넣으면 하부 작업 상태를 새 작업 기준으로 초기화합니다.
- 이전 악기 draft, 채널 옵션 draft, 분할 설정, 코드 편집 상태, 선택 서브탭을 그대로 이어받지 않습니다.
- MIDI 계열은 최초 채널 정보를 자동 적용해 별도 `적용` 없이 바로 재생/결과를 확인할 수 있습니다.
- 동일 작업에서 악기 설정의 `적용`만 누르는 경우에는 새 입력 초기화를 하지 않습니다.

## 재생과 draft 미리보기

- 악기 선택과 채널 옵션은 적용값과 편집 중 값(draft)을 분리합니다.
- draft가 적용값과 같으면 `취소 / 적용` 영역을 숨깁니다.
- 재생을 누르면 미적용 draft까지 임시 변환해 피아노롤과 연주에 반영합니다.
- 저장/복사는 확정 상태를 기준으로 하며 draft가 남아 있으면 계속 진행할지 확인 대화상자를 표시합니다.
- 원본 MIDI가 있으면 `원본` 모드로 원본 Program/Bank/Tempo 기준의 피아노롤과 재생을 확인할 수 있습니다.
- 빠른 제어는 여섯 채널, 배속, 볼륨, 음색을 제공합니다.

## 마지막 편집 상태 복원

- 단순 파일 불러오기만으로 복원 데이터를 만들지 않습니다.
- 실제 옵션/악기/MML 값을 하나라도 수정한 시점부터 저장합니다.
- 다음 방문 시 파일명 위치에 복원 버튼을 표시합니다.
- 복원 후에는 버튼을 없애고 파일명을 표시하며 편집을 계속할 수 있습니다.

## 공용 옵션

- 양자화: 64박 / 32박
- 템포 정리
- 템포 배율
- 시작 공백 (0.25초 단위)
- 별도 볼륨 생성 영역

## 하부 작업 영역

`악보 복사 / 악기 선택 / 채널 옵션 / 코드 편집` 네 탭을 사용합니다. 각 탭은 바깥 작업 상자 하나만 사용하며 내부 중첩 카드 배경/테두리를 제거합니다.

### 악보 복사

- 전체 악보: `로컬 저장 / Google 저장 / 복사`
- 분할 악보와 분할 탐색 위치를 지원합니다.
- 미적용 draft가 남아 있으면 저장/복사 전에 확인합니다.

### 악기 선택

채널 설정은 6개 리스트를 한 줄로 표시합니다.

```text
채널명
자동 / 고음 / 저음
모두 / 절반 / 안함
```

상단 구분은 `채널 / 노트 배치 / 노트 겹침`입니다.

- 채널 설정 목록 컨테이너 자체에는 좌우 패딩을 두지 않고 각 컨트롤의 내부 여백만 사용합니다.
- 악기 목록에는 작은 좌우 여백을 둡니다.
- 악기 목록 순서는 `악기명 → 노트 수 → 채널 버튼 → 듣기`입니다.
- 채널 버튼은 음소거 채널 버튼 계열의 활성/비활성 스타일을 사용하고 듣기 버튼 바로 왼쪽에 둡니다.
- 모바일도 가능한 한 한 줄을 유지하며 악기명/버튼이 겹치지 않습니다.
- 모든 악기 그룹을 접어도 목록 하단에 작은 여백을 남깁니다.
- `취소 / 적용`을 제공하며 draft가 적용값과 같으면 자동 숨김 처리합니다.

### 채널 옵션

기능 탭은 `쉼표 제거 / 볼륨 / 옥타브 / 반주 생성`입니다.

- 개별 채널 값을 바꿔도 일괄 적용 컨트롤을 임의로 같은 값으로 이동시키지 않습니다. 값이 섞이면 혼합 상태로 표시합니다.
- 쉼표 제거 문구는 `그대로 / 64박 / 32박 / 16박 / 8박 / 4박 / 모두`입니다.
- 볼륨은 각 채널 상단 한 줄에 `V값×노트 수` 분포를 표시하고, 그 아래에 `채널명 + 슬라이더/값`을 둡니다.
- 볼륨 분포 줄은 배경과 좌우 패딩 없이 표시합니다.
- 채널명 옆 별도 총 개수 표시는 두지 않습니다.
- 슬라이더를 움직이면 draft 기준 분포 개수를 즉시 갱신합니다.
- 볼륨 일괄/개별 슬라이더의 유효 길이는 동일하게 맞춥니다.
- 옥타브는 각 채널 최소/최대 범위와 변경 후 예상 범위를 함께 표시합니다.
- 모바일 옥타브는 채널명 공간을 우선 확보합니다.
- 반주 장르는 Pop/Jazz/Ballad/Bossa/Rock/Funk/Classical이며 draft 장르도 재생 미리보기에 반영합니다.

### 코드 편집

- `전체 채널 / 멜로디 / 화음1~5` 탭을 제공합니다.
- 글자 수/도움말 라인에 좌우 여백을 둡니다.
- 편집기 내부에 별도 카드 프레임을 추가하지 않습니다.

## MobiBeats

- `모비비트` 버튼은 현재 MML/악기 프리셋을 같은 페이지의 전체 화면 iframe 레이어에 전달합니다.
- Player 재생/프리뷰를 정지한 후 MobiBeats를 엽니다.
- `MML_RHYTHM_READY / LOADED / ERROR / CLOSE`를 처리합니다.
