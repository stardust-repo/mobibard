# Player 구현 스펙 스냅샷

마지막 갱신: 2026-11-06 KST  
출시 기준: 이 README와 현재 배포 소스

## 목적

여러 연주 파일을 최대 6개 마비노기 MML 채널로 변환하고, 원본과 현재 옵션 조합의 결과를 피아노롤/재생으로 확인한 뒤 복사·저장하는 상세 생성기입니다.

## 계산 원칙

```text
불러온 원본 + 악기/채널 배정 + 공용 옵션 + 채널 옵션 → 현재 결과 MML
```

옵션은 직전 결과에 누적하지 않습니다. 같은 입력/옵션 서명은 가능한 한 재계산을 생략합니다.

## 새 파일/붙여넣기

- 로컬, Google Drive, 붙여넣기로 새 소스를 넣으면 하부 작업 상태를 새 작업 기준으로 초기화합니다.
- 공용 포맷 계층에서 Sega VGM/VGZ·GYM과 S98 사운드칩 로그를 표준 MIDI로 복원해 기존 MML 변환 경로에 전달합니다.
- 오디오 파일(WAV/MP3/OGG/OPUS/M4A/AAC/FLAC/WEBM/AIFF)을 로컬 파일·Google Drive·드롭으로 넣으면 공용 Wave2MIDI로 악기별 MIDI로 변환해 기존 MIDI 불러오기 경로로 연결합니다(최대 30분). 상단의 `MIDI 추출` 버튼은 제거했습니다.
- 이전 악기 draft, 채널 옵션 draft, 분할 설정, 코드 편집 상태, 선택 서브탭을 그대로 이어받지 않습니다.
- MIDI 계열은 최초 채널 정보를 자동 적용해 별도 `적용` 없이 바로 재생/결과를 확인할 수 있습니다.
- 동일 작업에서 악기 설정의 `적용`만 누르는 경우에는 새 입력 초기화를 하지 않습니다.

## 재생과 draft 미리보기

- 악기 선택과 채널 옵션은 적용값과 편집 중 값(draft)을 분리합니다.
- draft가 적용값과 같으면 `취소 / 적용` 영역을 숨깁니다.
- 재생을 누르면 미적용 draft까지 임시 변환해 피아노롤과 연주에 반영합니다.
- 저장/복사는 확정 상태를 기준으로 하며 draft가 남아 있으면 계속 진행할지 확인 대화상자를 표시합니다.
- 원본 MIDI가 있으면 `원본` 모드로 원본 Program/Bank/Tempo 기준의 피아노롤과 재생을 확인할 수 있습니다.
- 빠른 제어는 여섯 채널, 배속, 볼륨, 음색을 제공합니다.

## 마지막 편집 상태 복원

- 단순 파일 불러오기만으로 복원 데이터를 만들지 않습니다.
- 실제 옵션/악기/MML 값을 하나라도 수정한 시점부터 저장합니다.
- 다음 방문 시 파일명 위치에 복원 버튼을 표시합니다.
- 복원 후에는 버튼을 없애고 파일명을 표시하며 편집을 계속할 수 있습니다.

## 공용 옵션

- 양자화: 64박 / 32박
  - 양자화 변경은 악기 선택 draft와 분리되어 즉시 다시 계산됩니다. 확정된 악기 선택은 그대로 유지하며 악기 `적용`을 요구하지 않습니다.
- 시작 공백 (0.25초 단위, 양자화 오른쪽)
- 볼륨 간소화 / 템포 간소화 (한 칸을 반으로 나눈 두 버튼, 적용 시 `N개 삭제` 표시, 볼륨 간소화는 변화량 1 고정·기본 해제)
- 템포 배율
- 페이드 인 / 페이드 아웃 (각각 0 / 1 / 2 / 4초 선택, 0이면 미적용)
  - 페이드 인은 전체 채널 중 첫 실제 발음 노트의 시작점을 V1로 두고 설정 시간 동안 각 노트의 원래 볼륨까지 증가
  - 페이드 아웃은 전체 채널 중 마지막 실제 발음 노트의 시작점이 V1이 되도록 설정 시간만큼 역산
  - 곡의 실제 노트 시작 구간이 설정한 페이드 시간보다 짧으면 가능한 길이에 맞게 자동 축소하며, 인/아웃이 겹치면 두 구간을 비율대로 줄여 처리
  - 원래 V0인 노트는 계속 V0으로 유지하며 지속음을 페이드 때문에 잘게 쪼개지는 않음

## 하부 작업 영역

`전체 / 악기 / 노트 / MML` 네 탭은 2번 영역(채널별 글자 수 아래)에 있고, 3번 영역에는 악보 복사만 남습니다. 각 탭은 바깥 작업 상자 하나만 사용하며 내부 중첩 카드 배경/테두리를 제거합니다.

### 악보 복사

- 전체 악보: `로컬 저장 / Google 저장 / 복사`
- 분할 악보와 분할 탐색 위치를 지원합니다.
- 미적용 draft가 남아 있으면 저장/복사 전에 확인합니다.

### 악기 (MML 채널 정리)

MIDI 변환은 공용 채널 정리 엔진(`plugins/common/mml-arranger.js`, `MabiMidi.arrangeMidiToMml`)을 씁니다. 위에서부터 아래 순서로 설정합니다.

1. 판단 기준: `악기 / 균형 / 문맥` (엔진 trust 1 / 0.5 / 0, 기본 균형)
2. 사용할 채널 수: 1~6 (기본 6)
3. 메인 주자 채널 수: 1~3, 사용할 채널 수를 넘을 수 없음 (기본 3)
4. 메인 주자 악기: 자동 또는 모비바드 악기 12종
5. 나머지 주자 악기(1채널씩): 자동, 모비바드 악기 12종, 드럼 심벌, 드럼 북. 드럼은 각각 한 채널만 고를 수 있고, 고르면 밀도(`최대한 넣기 / 중간 / 중요한 부분만`)가 나옵니다.

그 아래 `정리에 넣을 악기` 목록에서 체크한 악기 파트만 모아서 정리합니다.

- 처음 불러오면 모든 악기 파트가 체크되어 있습니다. 드럼 파트는 나머지 주자 악기로 드럼을 고른 경우에만 쓰입니다.
- 분류 제목의 체크로 같은 분류를 한 번에 넣거나 뺄 수 있고, 악기마다 듣기 버튼으로 미리 듣습니다.
- 악기별 채널 배정(예전 채널 버튼·일괄 선택)은 없앴습니다. 예전 세션을 복원하면 배정돼 있던 악기들이 `정리에 넣을 악기`로 옮겨집니다.
- 재생 음색은 엔진이 채널마다 고른 모비바드 악기를 기본 SoundFont 프리셋으로 바꿔 씁니다. 적용 전 draft 재생에도 draft 음색을 씁니다.
- `취소 / 적용`을 제공하며 draft가 적용값과 같으면 자동 숨김 처리합니다.

### 채널 옵션

기능 탭은 `쉼표 제거 / 볼륨 조절 / 볼륨 생성 / 옥타브`입니다. (반주 생성은 제거되었습니다.)

- 개별 채널 값을 바꿔도 일괄 적용 컨트롤을 임의로 같은 값으로 이동시키지 않습니다. 값이 섞이면 혼합 상태로 표시합니다.
- 쉼표 제거 문구는 `그대로 / 64박 / 32박 / 16박 / 8박 / 4박 / 모두`입니다.
- 볼륨은 각 채널 상단 한 줄에 `V값×노트 수` 분포를 표시하고, 그 아래에서 `원본 / 고정` 단일 모드 버튼과 하나의 슬라이더를 사용합니다. 원본 모드에서는 기존 볼륨에 -15~+15 상대 조정을 적용하고, 고정 모드에서는 슬라이더 값을 V0~V15 절대 볼륨으로 사용합니다.
- 볼륨 분포 줄은 배경과 좌우 패딩 없이 표시합니다.
- 채널명 옆 별도 총 개수 표시는 두지 않습니다.
- 슬라이더를 움직이면 draft 기준 분포 개수를 즉시 갱신합니다.
- 볼륨 일괄/개별 슬라이더의 유효 길이는 동일하게 맞춥니다.
- 옥타브는 각 채널 최소/최대 범위와 변경 후 예상 범위를 함께 표시합니다.
- 모바일 옥타브는 채널명 공간을 우선 확보합니다.
- 볼륨 생성은 장르(Pop/Jazz/Ballad/Bossa/Rock/Funk/Classical)를 공통으로 고르고, 강약(`적용 안 함 / 약하게 / 보통 / 강하게`)을 채널별로 정합니다. 장르를 고르기 전에는 강약 버튼이 비활성화되며, draft 값도 재생 미리보기에 반영합니다.
- 볼륨 생성 로직(v2, `plugins/common/mml-optimizer.js`의 `generateDynamicsMml`):
  - 모든 채널의 노트로 박자(3/4·4/4)와 마디 시작 위치를 추정합니다. 길게 울리는 음, 동시에 시작하는 음, 베이스 채널의 시작 위치에 가중치를 둡니다. 앞쪽 공백이 마디 단위가 아니어도 강박이 맞습니다.
  - 마디별 에너지(노트 밀도·연주 채널 수·음높이)를 모든 채널 공통으로 계산해 구간 단위로 커지고 작아집니다.
  - 채널별로 프레이즈 곡선(60% 지점 정점), 박자 강세, 엇박·당김음, 음 길이, 선율 윤곽(프레이즈 평균 대비·정점), 빠른 음 밀집을 더합니다.
  - 원래 채널 볼륨의 중앙값을 유지하도록 가운데를 맞춘 뒤 강약별 허용 폭 안에 담습니다. 히스테리시스로 잔떨림을 줄여 V 명령(글자 수)을 아낍니다.

## 2026-10-24 점검

- 재생 위치 막대 동기화가 파일이 없어도 매 프레임 진행 스타일·시간 눈금·분할 표시(MML 전체 문자열 비교 포함)를 다시 쓰던 문제를 고쳤습니다. 값이 바뀔 때만 DOM을 갱신하고, 변화가 없으면 0.25초 확인으로 내려갑니다(대기 중 CPU 약 19% → 0.2%).
- 기본 SoundFont는 처음 재생할 때 공용 `soundbank.js`가 불러옵니다(첫 화면 다운로드 약 7.1 MB → 1.6 MB).
- 포맷 모듈·Google API 로드 실패 오류 문구를 로케일 키로 바꿨습니다.

## 저장 메뉴 · 48 kHz (2026-10-25)

- `악보 복사`의 `오디오 저장 / 로컬 저장 / Google 저장` 버튼을 `저장` 버튼 하나와 메뉴(`오디오 저장 · MIDI 저장 · 로컬 저장 · Google 저장`)로 바꿨습니다. 기존 버튼을 메뉴 항목으로 옮겨 동작은 그대로입니다. 오디오를 만드는 동안 `저장` 버튼에 진행 문구가 보입니다.
- `MIDI 저장`: 저장용(최적화된) MML을 표준 MIDI로 저장합니다. 채널마다 재생 악기(사운드 프리셋)를 MIDI 프로그램으로 넣고, 기본 MobiBard 음원 프리셋은 Editor MIDI 내보내기와 같은 표로 GM 번호로 바꾸며, 뱅크 128은 드럼 채널로 보냅니다.
- 오디오 저장은 48 kHz 스테레오 OGG입니다.

## MobiBeats

- `모비비트` 버튼은 현재 MML/악기 프리셋을 같은 페이지의 전체 화면 iframe 레이어에 전달합니다.
- Player 재생/프리뷰를 정지한 후 MobiBeats를 엽니다.
- `MML_RHYTHM_READY / LOADED / ERROR / CLOSE`를 처리합니다.


## UI 구조

Player는 별도 스킨 파일을 사용하지 않습니다. 현재 출시 UI는 `styles.css`와 `js/app.js`에 직접 통합되어 있으며, 페이지는 최초 렌더부터 이 UI만 표시합니다.

### 기본 음원 다운로드 안내

- 처음 재생할 때 기본 음원(약 5 MB)을 내려받는 동안 "내려받는 중" 토스트를, 끝나면 "준비 완료" 토스트를 보여 줍니다. 실패하면 네트워크 확인 안내가 나옵니다.
- 미사용 함수 1개(`getAllowedMidiGroupsForSetting`)와 미사용 변수 2개를 제거했습니다.

### 가이드 이미지
`assets/tutorial/<언어>/01~06*.webp`는 현재 UI(전체·악기·노트·MML 탭) 기준으로 5개 언어 모두 다시 촬영했다. 악기 탭 이미지는 분류 일부를 접은 상태다.
