# Editor 구현 스펙 스냅샷

마지막 갱신: 2026-09-10 KST

출시 검증: v5.3 Beta. Editor 편집 기능은 유지하며 공용 포맷 계층에 VGM/VGZ, GYM, S98 입력을 추가했습니다. 정규화 기준은 현재 배포 소스와 `plugins/formats/NORMALIZATION_RULES.md`를 따릅니다.

## 목적

MML 채널과 참조 연주 파일을 피아노롤에서 시각적으로 편집하고, 채널·노트·템포·오디오 참조 자료를 하나의 작업 문서로 관리하는 편집기입니다.

## 파일 불러오기

- MOBIBARD AI/학습 결과 `.mbt`(MBT1)를 MIDI/악보 파일처럼 불러올 수 있습니다. MBT의 ON/ACTIVE/OFF를 노트로 복원하고 `악기별`/`Compact` 채널 배치(Compact에서도 음정 악기와 북·심벌즈 무음정 악기는 서로 다른 풀)를 선택한 뒤 기존 MIDI 불러오기 화면에서 미리보기·선택·새 프로젝트/추가 가져오기를 사용할 수 있습니다.
- 지원 확장자: `.mid`, `.midi`, `.kar`, `.seq`, `.sep`, `.sq`, `.bq`, `.psf`, `.psf1`, `.minipsf`, `.minipsf1`, `.psf2`, `.minipsf2`, `.ncsf`, `.minincsf`, `.2sf`, `.mini2sf`, `.sseq`, `.ssar`, `.sdat`, `.brseq`, `.rseq`, `.brsar`, `.bcseq`, `.cseq`, `.bcsar`, `.bfseq`, `.fseq`, `.bfsar`, `.musicxml`, `.xml`, `.mxl`, `.mus`, `.musx`, `.mnx`, `.mnx.json`, `.mscz`, `.mscx`, `.gp3`, `.gp5`, `.vsq`, `.vsqx`, `.vpr`, `.ust`, `.ustx`, `.svp`, `.s5p`, `.ccs`, `.xgm`, `.vgm`, `.vgz`, `.gym`, `.s98`
- 공용 포맷 등록소가 원본 파일을 표준 MIDI로 변환합니다. PlayStation SEQ/SEP·PS2 SQ/BQ·PSF1/PSF2(AKAO v1.0/v2 포함)와 Nintendo DS·Wii·3DS·Wii U·Switch 표준 시퀀스/사운드 아카이브 및 NCSF/2SF, Sega XGM과 VGM/VGZ·GYM·S98 사운드칩 로그도 같은 입력 경로를 사용합니다. 콘솔 전용 Bank와 드럼 슬롯은 가능한 경우 GM Bank 0/GM 타악기로 정규화되어 편집기 악기 선택과 미리듣기에 전달됩니다.
- 공용 MIDI 파서가 MIDI·KAR의 연주 및 가사·텍스트 이벤트를 해석하고, Editor는 그 결과를 피아노롤 문서 구조로 가공합니다.
- Classic Mac의 MacBinary Data Fork·Resource Fork·보조 헤더와 Program·Bank, running status, 템포·박자·조표는 공용 계층에서 처리합니다.
- 확장자가 보존되지 않은 Classic Mac 컨테이너를 위해 `.bin`·`.macbin`도 선택할 수 있으며, 내부 파일명과 바이너리 시그니처로 실제 형식을 판별합니다.
- MUSX·MNX·MuseScore 입력은 기본 재생 정보를 보존하며 고급 기보와 레이아웃은 단순화됩니다.
- 통합 불러오기 대화상자는 전체 지원 형식과 MIDI·KAR, XMI·HMP·HMI, Tracker(MOD/S3M/XM/IT), MusicXML, MNX, Finale, MuseScore, Guitar Pro, PlayStation, Nintendo, Sega, VOCALOID, UTAU, OpenUtau, Synthesizer V, CeVIO, 모비바드 프로젝트, 3MLE·MabiIcco·MML 필터를 제공합니다. Classic Mac은 별도 카테고리 없이 전체 또는 관련 옛 포맷군에서 `.bin`·`.macbin`을 선택하면 내부 형식을 자동 판별합니다.
- MIDI 참조, MML 가져오기, 오디오 가져오기도 같은 공용 파일 선택 경로를 사용하며 브라우저 미지원 시 기존 파일 입력으로 자동 대체됩니다.
- 지원 파일 팝업은 표준 음악·악보, 음악 편집기, 콘솔, 보컬 편집기 등으로 구분하며 VOCALOID·UTAU·OpenUtau·Synthesizer V·CeVIO를 서로 다른 제품군으로 표시합니다.
- 지원 파일 팝업에는 Classic Mac 컨테이너를 별도 형식이나 안내 항목으로 표시하지 않으며, 선택 뒤 공용 입력 계층이 자동 판별합니다.
- 불러오기 팝업은 긴 파일명이나 긴 텍스트가 있어도 뷰포트 폭을 넘겨 늘어나지 않도록 내부 요소의 최소 폭과 말줄임을 제한하며 하단 작업 버튼을 항상 팝업 안에 유지합니다.

## 편집

- 채널 추가·삭제·복제·순서 변경·표시·음소거를 지원합니다.
- 노트 선택·복사·붙여넣기·이동·길이·볼륨 편집을 지원합니다.
- MIDI/악보 파일은 양자화된 위치가 아니라 원본 MIDI tick 시간으로 먼저 성부를 분리한 뒤 1/64 또는 1/32 격자에 양자화합니다. 같은 Bank/Program의 여러 트랙은 하나의 악기 그룹으로 합치되 원본 Track·Port·Channel과 음역·직전 음정을 성부 배정 우선순위에 반영합니다. 원본에서는 순차적이지만 양자화 때문에 같은 칸에 겹친 노트는 새 채널을 만들지 않고 해당 성부의 대표 노트로 축약합니다. `64박 겹침 무시`는 원본 타이밍에서 1/64 이하의 작은 순차 겹침을 같은 성부로 허용하며, 같은 시작점의 실제 화음은 항상 별도 성부로 유지합니다.
- 파일 불러오기에서 `악기당 최대 3채널`을 선택하면, 원래 4개 이상의 성부가 필요한 악기도 최대 3개의 편집 채널에 재배치합니다. 이 채널 수 제한기는 `N`을 인자로 받는 일반 함수로 구현되어 있으며, 빈 채널을 우선 사용한 뒤 필요하면 같은 채널의 시간 영역에 노트를 겹쳐서라도 모든 노트를 보존하는 방식으로 압축합니다. 기본값은 해제입니다.
- MIDI 악기 그룹은 Drum을 제외하고 Bank + Program 조합을 기준으로 구분하여 서로 다른 Bank의 동일 Program이 잘못 합쳐지지 않도록 합니다.
- MML 가져오기·내보내기와 프로젝트 저장·불러오기를 지원합니다. MML 내보내기를 실행하면 편집 채널 선택 팝업을 먼저 표시하며 모든 채널은 기본 체크 해제 상태이고 선택한 채널만 하나의 MML로 클립보드에 내보냅니다.
- 템포 이벤트와 참조 오디오를 작업 문서에서 관리합니다.

## 다국어 처리

- 공용 규칙은 `../plugins/common/I18N_SPEC.md`를 따릅니다.
- Editor locale의 `strings`와 `patterns` key는 영어 semantic key만 사용하며 5개 언어가 동일한 key 집합을 유지합니다.
- `<head>`에서 URL/공용 저장 설정/브라우저 언어를 먼저 결정하고 한국어 기준 catalog와 선택 catalog를 앱 및 Analytics보다 먼저 준비합니다.
- 정적 HTML은 읽을 수 있는 한국어 fallback 본문과 `data-i18n` semantic key를 함께 사용합니다. 새 동적 문구는 `MobibardI18n.t(key)`를 사용합니다.

### 2026-09-19 통합 불러오기 팝업 정리
- MIDI/KAR 및 변환 가능한 음악 파일은 한 개의 통합 불러오기 팝업을 사용합니다. 상단은 `옵션` / `채널` 두 줄로 구성되며, 옵션 줄에는 파일 선택·양자화·64박 겹침 무시·악기당 최대 3채널을, 채널 줄에는 전체 선택/해제·파일 요약·원본 듣기를 표시합니다.
- 3MLE / MabiIcco(MMI) / MML 텍스트도 별도 팝업 없이 같은 통합 팝업을 사용합니다. 이 계열은 MIDI 옵션 줄을 표시하지 않고 텍스트/파일 입력과 채널 선택만 제공합니다.
- 통합 팝업의 원본 듣기와 채널별 미리듣기는 SoundBank 준비 및 pitch preload 후 재생합니다.
- MML 계열 `새로 열기`는 파일의 템포 맵을 새 프로젝트에 적용하고, `추가`는 파일의 절대 연주 시간을 현재 프로젝트 템포 맵의 beat 위치로 재계산해 노트를 추가합니다.

## 2026-09-21 쉼표 정리 및 MML 내보내기 최적화

- `편집 > 쉼표 정리`를 추가했습니다. 현재 채널 또는 전체 채널을 대상으로 1/64·1/32·1/16·1/8·1/4 이하 또는 모든 쉼표를 정리할 수 있습니다.
- 쉼표 정리는 Player와 동일한 공용 `MabiOptimizer.trimShortRestsMml()` 규칙을 사용합니다. 곡 시작 전 공백은 유지하고, 조건에 맞는 중간 쉼표는 앞 노트 길이에 흡수합니다. 적용 전 제거 개수/박자 미리보기를 표시하며 적용은 편집 히스토리 한 단계로 기록됩니다.
- Editor의 MML 내보내기는 공용 `MabiOptimizer.optimizeMml()`을 통과한 결과를 사용합니다. 채널별 글자 수와 자동 분할 판단도 최종 최적화 MML 기준으로 계산합니다.
- 6파트를 넘는 Editor 출력은 첫 6파트를 Player와 같은 방식으로 묶어 최적화하고, 추가 파트도 개별 최적화하면서 기존 템포를 덮는 불필요한 `T120`은 삽입하지 않습니다.

## 프로젝트 저장 포맷 v29

- 프로젝트 JSON은 `schema-rows-v2` 인코딩을 사용합니다. 반복 객체 배열의 프로퍼티명은 파일 전체 공유 스키마에 한 번만 기록하고, 실제 데이터는 스키마 번호와 값 행으로 저장합니다.
- 상위 JSON 구조와 필드명 스키마는 유지되므로 새 필드 추가/버전 마이그레이션이 가능하며, v28 이하의 기존 프로젝트와 v27 이하의 일반 JSON 프로젝트도 계속 불러올 수 있습니다.
- 일반 저장, Google Drive 저장, IndexedDB 자동 저장에 Undo/Redo 히스토리(현재 위치 포함)를 함께 저장하고 복원합니다.
- v29에서는 1단계 채널 그룹 구조(`groupId` 및 그룹 메타데이터)를 프로젝트/히스토리에 함께 저장합니다.

## 2026-10-23 불러오기: 오디오 AI 변환 (Beta)

- `파일 > 불러오기`(통합 불러오기 팝업의 `파일 선택` 포함)에서 오디오(`wav`·`mp3`·`ogg`·`oga`·`opus`·`m4a`·`aac`·`flac`·`webm`·`aif`·`aiff`)를 선택하면 공용 모듈 `plugins/ai/wave2midi/`(Wave2MIDI, 모델 v0.1)로 악기별 MIDI를 만든 뒤 기존 통합 불러오기 팝업에서 미리듣기·채널 선택·양자화·새로 열기/추가를 그대로 사용합니다. 별도 `MIDI 추출` 메뉴(외부 MuScriptor 링크)는 제거했습니다.
- 팝업 제목은 `오디오 · AI 변환 (Beta) 불러오기`이며, 변환 중에는 채널 목록 자리에 진행 막대와 단계(모델 다운로드 MB, 분석 구간 n/m)를 표시합니다. 완료되면 모델 버전·노트 수·소요 시간을 알림으로 보여 줍니다.
- 변환은 브라우저 Worker에서 진행하며 파일은 업로드되지 않습니다. 양자화 등 옵션을 바꾸면 AI를 다시 실행하지 않고 변환된 MIDI만 다시 해석합니다.
- 팝업의 취소·닫기·Esc는 실행 중인 변환 Worker를 종료합니다. 최대 길이는 10분입니다.
- AI 모델(39 MB)은 처음 한 번 내려받아 IndexedDB에 저장하고 영구 저장소(`navigator.storage.persist()`)를 요청합니다. 이후에는 네트워크 없이 SHA-256 검증 후 사용하며, `meta.json`만 바뀐 경우에도 다음 사용 때 갱신됩니다.
- 오디오 참고 트랙으로 넣는 기존 `오디오 가져오기` 기능은 그대로입니다.
- 모델은 startdust-io가 제작한 MIT License 모델이며, 변환 진행 패널에 `Wave2MIDI v0.1 · startdust-io · MIT License`를 표시하고 `plugins/ai/wave2midi/model/LICENSE`로 연결합니다.

## 2026-10-24 내보내기·레이아웃 수정

- **MIDI 내보내기**: MML 내보내기처럼 채널 선택 팝업을 먼저 표시합니다(기본: 노트가 있는 모든 채널 선택, 그룹 단위 선택·드래그 선택 지원). 기본 음색 사용 시 모비바드 프리셋 번호(0~13)를 GM 악기 번호로 바꿔 기록합니다(Piano 0, Chalumeau 71, Flute 73, Harp 46, Lute 24, Mandolin 15, Violin 40, Xylophone 13, MusicBox 10, Guitar 25, Harmonica 22, Cat 53, BigDrum·Cymbals → 채널 10 드럼). 이전에는 프리셋 번호가 그대로 기록되어 다른 재생기에서 대부분 피아노 계열로 재생되었습니다. 악기 수가 15 이하이면 악기마다 MIDI 채널 하나를 쓰고, 넘을 때만 빈 구간에서 채널을 재사용합니다.
- **오디오 내보내기**: 같은 채널 선택 팝업을 사용하며 렌더링·인코딩 진행률을 표시합니다. 노트를 OfflineAudioContext에 한꺼번에 연결하지 않고 2초 단위(suspend/resume)로 연결해, 3분·15,000노트 기준 10분 이상 걸리던 렌더링이 약 40초로 줄었습니다(렌더 결과 PCM은 기존과 동일, 최대 오차 4×10⁻⁷).
- **불러오기 선택기**: 공용 `supported-files-ui.js`가 `application/octet-stream` 대신 전용 MIME 키를 써서 Chrome 파일 선택기에 `.exe`/`.com`이 함께 표시되지 않습니다(Simple·Player 공통).
- **iPhone**: 상단 툴바를 작업 영역 위 쌓임 층(z-index 1400, 팝업 1500 아래)으로 올려 파일·편집·설정 메뉴가 채널 탭과 전체 트랙바 아래로 깔리지 않게 했습니다.
- **MML 내보내기**: 좌우 배치(최대 크기)에서 왼쪽 채널 목록이 남은 높이를 모두 쓰고 그 안에서 스크롤됩니다.
- **쉼표 정리·파트 자동 설정**: 마디 편집처럼 채널/히스토리/단축키 탭 줄 자리에 제목을 표시합니다.

- **채널 목록 통일**: 마디 편집 · 쉼표 정리 · 파트 자동 설정의 채널 목록을 채널 삭제와 같은 채널 트리 템플릿(색상 막대 행, 📂 그룹 행 + `선택/전체` 개수, 오른쪽 ○/✓ 토글)으로 바꿨습니다. 행 아무 곳이나 눌러도 선택이 바뀌고, 그룹 토글은 하위 채널 전체를 켜고 끕니다(일부만 선택되면 `–`와 점선 테두리). 선택되지 않은 행은 흐리게 표시됩니다. 쉼표 정리는 채널별 영향 쉼표 수를 행 오른쪽에 작게 유지합니다.
- **로케일**
  - `group.name_required` 등 누락 키를 추가했습니다.
  - 번역기(`js/language-manager.js`)가 `data-i18n*` 표시가 있는 요소도 원문 번역을 거치도록 바꿨습니다. 앱이 실행 중에 이런 요소의 title/aria-label/텍스트를 한국어로 다시 써도(예: `전체 재생 볼륨 75%`, `왼쪽 패널 닫기`) 이제 번역됩니다. 패턴에 잡힌 값이 다시 한국어 UI 문구면(예: `분자 1 증가`의 `분자`) 그 값도 번역합니다.
  - 튜토리얼 7단계 전체, 상단 튜토리얼/Beta 설문 버튼, 정보줄(전체/N파트/글자 수 설명), 단축키 `휠`, 각종 aria-label을 5개 언어로 번역했습니다.

- **버그**: 정의되지 않은 `selectMidiGroupFromTree`, `activateMidiGroupFromRoll`, `isMidiDocumentVisible` 호출(예전 프로젝트의 원본 MIDI 트리·피아노롤·우클릭 메뉴에서 ReferenceError)을 구현했습니다.
- **최적화**: 재생 중 매 프레임 바뀌던 재생 시간 툴팁을 값이 바뀔 때만 갱신하고 `i18nText`로 만들어 번역기 패턴 대조를 없앴습니다. 그리기 경로에서 결과를 버리던 계산 몇 곳을 정리했습니다. 기본 SoundFont는 공용 `soundbank.js`가 첫 사용 시 불러옵니다(아래 참고).
