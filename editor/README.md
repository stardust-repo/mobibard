# 모비바드

브라우저에서 바로 실행하는 피아노롤 기반 음악 편집기입니다. 별도 빌드 과정 없이 `index.html`을 열어 사용할 수 있으며 PC 마우스와 태블릿 터치 조작을 함께 지원합니다.


## 자동 저장

- 편집 내용과 채널·오디오의 표시·음소거 상태를 브라우저에 자동 저장합니다.
- 노트·채널·템포 변경은 짧은 지연 뒤 자동 저장되며, 탭을 숨기거나 페이지를 떠날 때도 마지막 저장을 시도합니다.
- 같은 브라우저에서 새로고침하거나 편집기를 다시 열면 가장 최근 자동 저장 상태를 복구합니다.
- 자동 저장은 IndexedDB를 우선 사용하며, 지원되지 않는 환경에서는 로컬 저장소를 보조 수단으로 사용합니다.
- 수동 `저장`은 기존처럼 프로젝트 JSON 파일을 내려받는 기능이며 자동 저장과 별도로 유지됩니다.

## 데이터 처리 원칙

- 편집, 선택, 이동, 복사, 잘라내기, 붙여넣기, 저장, 재생은 모두 **노트 데이터**를 기준으로 처리합니다.
- 노트 데이터는 음정, 시작 위치, 길이, 마비노기 볼륨 `V0~V15`와 재생용 velocity를 포함합니다.
- MML·3MLE·MMI 불러오기는 원본 텍스트를 한 번만 해석해 채널 노트 데이터로 변환합니다. 변환이 끝난 뒤 편집·저장·재생 과정에는 원본 MML 문자열이 개입하지 않습니다.
- MML 출력 변환은 `파일 > MML 내보내기`를 실행한 순간에만 수행합니다.

## 화면 구성

- 최상단: 파일·편집 메뉴, 한 덩어리로 묶인 처음·재생/정지·끝 이동, 재생 시간, 소형 수직 전체 볼륨·배속·확대 배율 슬라이더, 편집 도구, 음표 단위, Guest 설정
- 왼쪽 패널 상단: `채널`과 `히스토리` 전환 탭
- 왼쪽 `채널` 화면: 모든 편집 채널을 하나의 평면 목록으로 표시하고, MIDI·MusicXML에서 불러온 악기도 같은 일반 편집 채널로 추가
- 왼쪽 `히스토리` 화면: 최대 100단계 편집 내역, 되돌리기와 다시적용
- 중앙: 타임라인, C0~B8 피아노 건반과 피아노롤, 하단 고정 오디오 배치 트랙

왼쪽 패널과 피아노롤은 세로 구분선으로 나뉩니다. 피아노 건반 위의 `패널 닫기` 버튼으로 왼쪽 전체 패널을 숨길 수 있으며, 숨긴 뒤에는 같은 위치의 `패널 열기` 버튼으로 다시 표시합니다.

## 파일 메뉴

- **새 파일**: 새 프로젝트를 만듭니다.
- **불러오기**: 하나의 파일 선택 창에서 모비바드 프로젝트 JSON, MML·3MLE·MMI 호환 파일, MIDI·MusicXML을 모두 엽니다. 저장한 프로젝트 파일은 별도 가져오기 팝업 없이 즉시 열립니다.
- **저장**: 현재 프로젝트를 JSON으로 저장합니다.
- **오디오 불러오기**: 브라우저가 재생할 수 있는 WAV·MP3·OGG·M4A·AAC·FLAC·WebM 등의 음원을 왼쪽 목록과 피아노롤 하단 오디오 트랙에 추가합니다. 오디오는 통합 불러오기와 분리되어 있습니다.
- **MML 내보내기**: 현재 선택 노트 또는 현재 편집 채널을 그 순간 MML로 변환해 클립보드에 기록합니다.

## 편집 메뉴

키보드가 없는 태블릿에서도 다음 작업을 버튼으로 실행할 수 있습니다.

- 되돌리기 / 다시적용
- 복사 / 잘라내기 / 붙여넣기
- 전체 선택 / 삭제
- 선택 노트 볼륨 수정

복사와 잘라내기는 MML이 아니라 모비바드 노트 데이터로 동작합니다.


## 오디오 배치 트랙

`파일 > 오디오 불러오기`로 음악 파일을 선택하면 왼쪽 채널 목록에 오디오 항목이 추가되고, 피아노롤 하단의 고정 오디오 트랙에 하나의 블록으로 배치됩니다.

- 새 오디오는 현재 빨간 재생선 위치에 배치됩니다.
- 블록 가운데를 마우스 또는 터치로 끌어 시작 위치를 옮길 수 있습니다.
- 블록의 왼쪽·오른쪽 끝을 끌어 재생 구간의 시작과 끝을 조절할 수 있습니다.
- 위치와 길이는 현재 편집 단위에 맞춰 스냅됩니다.
- 오디오 트랙은 피아노롤과 같은 시간축과 가로 스크롤을 사용하므로 재생 자동 스크롤 중에도 노트와 음원의 위치가 함께 움직입니다.
- 재생선이 블록 시작점에 도달하면 음원이 시작되고 블록 끝점에서 정지합니다. 중간 위치에서 재생하면 해당 오디오 위치부터 이어서 재생합니다.
- 전체 배속과 전체 볼륨을 함께 따르며, 왼쪽 계층에서 표시·숨김과 음소거를 따로 설정할 수 있습니다.
- 오디오 항목을 선택하면 파일명, 배치 시작·끝 위치와 원본 재생 시간을 확인하고 색상·시작 오프셋·개별 배속 또는 삭제를 조작할 수 있고, 개별 볼륨은 삭제 버튼 오른쪽의 슬라이더로 조절합니다. 새 오디오의 개별 볼륨은 30%, 배속은 1×입니다.
- 오디오 블록은 시작 시간이 늦을수록 트랙 위쪽에 오도록 자동 정렬되며, 블록을 드래그해 시간 순서를 바꾸면 세로 순서도 즉시 갱신됩니다.

오디오 원본 바이트는 IndexedDB 자동 저장에 함께 보관하므로 같은 브라우저에서 새로고침해도 복구됩니다. 수동 프로젝트 JSON은 파일 크기를 작게 유지하기 위해 배치 정보만 저장하며, 다른 브라우저나 기기에서 열었을 때는 같은 파일을 다시 불러와 연결해야 합니다.

## MML / 3MLE / MMI 불러오기

`파일 > 불러오기`에서 `.mml`, `.3mle`, `.mmi`, `.txt` 파일을 선택할 수 있습니다. 3MLE·MMI는 파일 안의 채널 목록을 체크박스로 보여주며 필요한 채널만 가져올 수 있습니다.

### 표준 MML

- `MML@...;`로 감싼 형식과 감싸지 않은 단일 MML 파트를 읽습니다.
- 쉼표로 구분된 각 음성을 별도의 새 일반 채널로 추가합니다.
- 템포 `T`, 옥타브 `O`, 기본 길이 `L`, 볼륨 `V`, 쉼표 `R`, 옥타브 이동 `< >`, 임시표, 점음표와 타이 `&`를 노트·템포 데이터로 변환합니다.

### 3MLE 프로젝트

- `[Channel1]`, `[Channel2]`처럼 구분된 채널을 감지합니다.
- 채널 주석 이름을 읽어 새 채널명으로 사용합니다.
- 감지된 채널 목록은 처음에 모두 선택되며, 체크박스로 필요한 채널만 남길 수 있습니다.
- `[Channel1]` 또는 파일 전체의 전역 템포를 선택 채널에 적용합니다.
- `EXx`, `Y`, `@`, `~` 같은 3MLE 전용 명령은 제거하고, 15보다 큰 볼륨은 `V0~V15` 범위로 환산합니다.

### MMI 호환

- MabiIcco `.mmi` 안의 `MML@...;`, MML 키·태그·문자열 후보를 찾아 채널 목록으로 표시합니다.
- 가능한 경우 트랙·파트 이름을 채널명에 반영합니다.
- 오래된 길이 `6`, `12`, `24`, `48` 같은 비표준 길이는 1/64 음표 조합으로 근사해 읽습니다.

공통 동작:

- MML 계열은 1/64 음표 기준으로 변환합니다. MIDI/MusicXML 전용 양자화·원본 듣기 컨트롤은 표시하지 않습니다.
- `추가`는 선택한 음성/채널을 현재 편집 프로젝트 뒤에 새 채널로 추가하며 현재 프로젝트 템포는 유지합니다.
- `새로 열기`는 현재 프로젝트를 비우고 선택한 음성/채널로 새 프로젝트를 만들며, 원본에 명시된 템포가 있으면 함께 적용합니다.
- 변환이 끝나면 노트·템포 데이터만 유지하며 재생 중 원본 MML을 다시 파싱하지 않습니다.

## 일반 채널

- 새 채널에는 `Ch1`, `Ch2`처럼 고유 번호 기반 이름이 부여됩니다. 중간 채널을 삭제해도 나머지 채널 번호는 다시 매겨지지 않습니다.
- 일반 채널은 왼쪽 `채널` 탭의 `편집 채널` 계층 아래에 표시됩니다.
- 채널 항목을 마우스나 터치로 위아래 드래그하면 행 자체가 새 위치로 이동해 미리 보이고, 실제 순서 변경은 놓는 순간 반영됩니다. 마우스 드래그 중 우클릭하면 순서 변경을 취소합니다.
- 긴 채널명은 목록 폭에 맞춰 생략 표시되며, 아래 채널 편집 영역에서 이름을 수정할 수 있습니다.
- 채널 색상은 목록 항목의 테두리·배경·글자색과 피아노롤 노트 색상에 반영됩니다.
- 채널 편집 영역에서는 색상 선택기와 채널명이 하나의 결합된 입력 상자로 표시되며, 색상 버튼 전체 배경이 현재 채널 색상으로 표시됩니다.
- 각 채널 항목의 오른쪽 끝에는 표시·숨김 버튼과 음소거·해제 버튼이 항상 배치됩니다.
- 표시 여부와 음소거는 서로 독립적으로 동작하며 히스토리에 기록되지 않습니다.
- 채널 삭제는 확인 대화상자를 거친 뒤 실행됩니다.
- 채널 전체와 선택 노트를 노트 데이터로 복사·잘라내기 할 수 있습니다.
- 선택 도구에서 아무 노트도 선택되지 않았을 때 다른 채널의 비쳐 보이는 노트를 누르면 해당 채널로 이동하고 그 노트를 선택합니다.

### 단선율 채널 규칙

일반 편집 채널 하나는 MML 한 성부와 1:1 대응하도록 단선율로 유지됩니다.

- 한 채널 안에서 두 노트가 시간상 겹칠 수 없습니다.
- 노트 생성·이동·길이 변경으로 기존 노트와 겹치면 새 편집 구간을 우선합니다. 앞에서 이어지던 노트는 새 노트 시작점까지 잘리고, 새 구간 안에서 시작하는 기존 노트는 삭제됩니다. 붙여넣기는 기존 충돌 방지 규칙을 유지합니다.
- 예전 프로젝트에 겹친 노트가 들어 있으면 불러올 때 같은 시작 위치에서는 강한 노트를 우선하고, 앞 노트는 다음 노트 전까지로 보정합니다.
- 화음은 여러 일반 채널로 나누어 편집합니다.

## 노트별 볼륨

- 일반 노트를 선택한 뒤 채널 도구의 `V` 버튼, 편집 메뉴 또는 노트 컨텍스트 메뉴를 통해 볼륨 팝업을 열 수 있습니다.
- 여러 노트를 선택해 한 번에 `V0~V15` 값을 적용할 수 있습니다.
- `V0`은 무음이며 피아노롤에서 매우 흐리게 표시됩니다.
- 모든 일반 노트의 왼쪽 시작점 바로 위, 노트 바깥쪽에 현재 `V0~V15` 값이 표시됩니다.
- 편집 가능한 채널에서 노트를 하나 이상 선택한 상태로 `Alt + 마우스 휠`을 돌리면 선택 노트의 볼륨을 한 단계씩 올리거나 내립니다.
- 볼륨 변경은 편집 히스토리에 기록됩니다.

## MIDI / MusicXML 가져오기

MIDI와 MusicXML은 `파일 > 불러오기`의 같은 가져오기 팝업을 사용합니다. 형식 정보 줄은 따로 두지 않고 `MIDI 불러오기` 또는 `MusicXML 불러오기`라는 팝업 제목으로 구분합니다.

- 정보줄 아래에서 **64박 / 32박 양자화**를 선택할 수 있고, `선택 듣기`로 체크한 악기만 또는 `원본 듣기`로 파일 전체를 미리 들을 수 있습니다.
- 악기 목록은 처음에 모두 체크되어 있으며 각 악기 오른쪽 `듣기` 버튼으로 미리 들은 뒤 필요 없는 악기는 체크를 끌 수 있습니다.
- `추가`는 선택한 악기를 현재 프로젝트의 **일반 편집 채널**로 바로 추가합니다. 별도 MIDI/MusicXML 원본 문서나 읽기 전용 탭은 만들지 않습니다.
- `새로 열기`는 현재 프로젝트를 비우고 선택한 악기들로 새 프로젝트를 구성하며 파일의 템포 맵을 사용합니다. `추가`는 현재 프로젝트 템포를 유지합니다.
- 같은 GM 악기는 같은 색과 악기 설정을 사용합니다. 드럼은 `Drums (GM Channel 10)`으로 생성됩니다.
- 편집 채널은 단선율이므로 한 악기에 화음이 있으면 모든 노트를 보존하면서 필요한 만큼 여러 편집 채널로 자동 분리합니다.

MusicXML `.musicxml`, `.xml`, 압축 MusicXML `.mxl`은 먼저 표준 MIDI 이벤트 데이터로 변환한 뒤 MIDI와 같은 악기 병합·양자화·선택 가져오기 흐름을 사용합니다.

### MIDI / MusicXML 가져오기 보정

- 노트 시작 위치와 길이를 선택한 1/64 또는 1/32 음표 위치로 양자화합니다.
- 음정·시작 위치·길이가 완전히 같은 중복 노트는 하나로 병합합니다.
- MIDI velocity는 마비노기 볼륨 `V0~V15`로 변환합니다.
- MIDI는 SMF Format 0·1과 PPQN 시간 형식을 지원하며 MusicXML은 `score-partwise`, `score-timewise`, `.mxl`을 처리합니다.

## 노트 복사·붙여넣기

복사 데이터에는 다음 정보가 들어갑니다.

- 음정
- 복사 묶음 안에서의 상대 시작 위치
- 노트 길이
- 마비노기 볼륨과 재생용 velocity

지원 동작:

- 선택한 일반 노트 복사·잘라내기
- 현재 일반 채널 전체 복사·잘라내기
- 선택한 MIDI·MusicXML 노트 복사
- 현재 MIDI·MusicXML 악기 전체 복사
- 일반 채널의 빨간 재생선 위치에 붙여넣기

브라우저가 시스템 클립보드 권한을 허용하면 노트 데이터를 JSON 형식으로 함께 기록해 다른 모비바드 창에서도 붙여넣을 수 있습니다. 붙여넣을 노트끼리 겹치거나 현재 일반 채널의 기존 노트와 겹치면 작업하지 않습니다.

## 재생과 성능

재생 중에는 MML을 만들거나 파싱하지 않습니다. 모든 편집 채널의 노트 데이터를 직접 시간 정보로 변환합니다.

- 전체 곡의 오디오 노드를 재생 시작 순간 한꺼번에 만들지 않습니다.
- 현재 시점부터 약 0.65초 앞의 노트만 순차적으로 예약합니다.
- 한 스케줄러 호출의 처리량과 실행 시간을 제한해 UI 스레드를 오래 점유하지 않도록 했습니다.
- 끝난 보이스는 즉시 정리하며 동시 보이스 수를 PC와 터치 환경에 맞게 제한합니다.
- 같은 순간에 지나치게 많은 음이 몰리면 강한 음을 우선해 브라우저 오디오 엔진 정지를 방지합니다.
- 동시에 소리 나는 채널은 1~2개까지 원래 음량을 유지하고, 3개째부터 최대 동시 발음 수에 따라 제곱근 방식으로 전체 재생 게인을 자동 보정합니다. 노트 velocity와 음색 선택은 바꾸지 않습니다.
- 재생 중 확대했을 때 기존 확대 기준점이 빨간 재생선을 화면 왼쪽 밖으로 밀어내는 경우, 확대 기준점을 재생선으로 자동 이동합니다. 사용자가 가로 스크롤바를 오른쪽으로 움직여 재생선이 이미 왼쪽 밖으로 벗어난 경우에도 스크롤 조작을 놓는 즉시 재생선을 안전한 왼쪽 여백으로 복귀시키며, 그 상태에서 확대·축소해도 재생선을 기준으로 위치를 다시 맞춥니다. 이전 배율에서 진행 중이던 자동 스크롤도 함께 취소해 새 위치를 덮어쓰지 않게 합니다.
- `V0` 노트는 오디오 예약과 재생 건반 표시에서 제외합니다.

### 전체 볼륨과 배속

- 전체 볼륨 기본값은 `100%`이며 `0~150%` 범위의 수직 슬라이더로 조절합니다.
- 재생 배속은 `0.75×~1.5×` 범위의 수직 슬라이더로 조절하며 기본값은 `1×`입니다.
- 볼륨·배속·배율 팝업에는 기본값으로 되돌리는 `초기화` 버튼이 있습니다.
- 볼륨과 배속 선택값은 브라우저에 저장됩니다.
- 재생 중 다른 편집 채널을 선택해도 현재 재생은 중단되지 않습니다.

## 피아노롤 렌더링과 스크롤

- 가로 방향은 현재 화면 주변까지 여유 있게 버퍼링한 캔버스에 그립니다.
- 세로 방향은 고정된 C0~B8 전체 높이를 하나의 버퍼에 유지합니다.
- 세로 스크롤 중 새 캔버스가 준비되기 전 빈 화면이 나타나는 구조를 제거했습니다.
- 일반 채널과 MIDI 악기 노트는 마디별 인덱스로 찾고 현재 화면 주변 노트만 그립니다.
- iPad처럼 기본 스크롤바가 숨겨지는 환경을 위해 피아노롤 전용 가로·세로 스크롤바를 제공합니다.

## 표시와 음소거

상단의 전역 음소거 버튼과 별도 음소거 팝업은 사용하지 않습니다. 왼쪽 `채널` 트리의 각 항목 오른쪽 끝에서 직접 조작합니다.

- 일반 편집 채널: 채널별 표시·숨김, 음소거·해제

표시와 음소거는 보기·재생 상태이므로 편집 히스토리에 기록되지 않습니다.

## 히스토리

- 왼쪽 패널 상단의 `히스토리` 탭을 눌러 채널 계층과 전환합니다.
- 최신 편집이 위쪽, 오래된 편집이 아래쪽에 표시됩니다.
- 패널 안에는 되돌리기와 다시적용 버튼이 있으며, 목록 항목을 눌러 해당 시점으로 이동할 수 있습니다.
- 피아노 건반 위 왼쪽 버튼은 왼쪽 전체 패널 상태에 따라 `패널 닫기` 또는 `패널 열기`로 표시됩니다.
- 최대 100개의 실제 편집 상태를 보관합니다.
- 노트 생성·삭제·이동·길이·볼륨 변경, 채널 추가·삭제·이름·색상·순서, 템포 변경, MIDI·MusicXML 가져오기 등이 기록됩니다.
- 음소거, 표시·숨김, 선택 채널, 재생선, 확대 배율, 음계 간격 같은 보기·재생 상태는 기록하지 않습니다.

## 템포 터치 편집

- PC에서는 타임라인 템포 박스를 우클릭해 수정하거나, 이동 가능한 템포를 좌우로 드래그할 수 있습니다.
- 태블릿에서는 템포 박스를 짧게 탭하면 `32~255` BPM 숫자 입력 팝업이 열립니다.
- 이동 가능한 템포는 터치 드래그로 위치를 바꿀 수 있고, 드래그하지 않고 탭하면 값 편집 팝업이 열립니다.
- 0번 템포는 위치와 삭제가 고정되지만 BPM 값은 같은 팝업에서 수정할 수 있습니다.
- 빈 타임라인을 길게 누른 뒤 `템포 추가`를 선택하면 같은 터치용 입력 팝업으로 새 템포를 추가합니다.

## 가이드선과 확대

- 편집 음표 단위는 노트 배치·이동·길이 조절의 스냅에만 사용됩니다.
- 화면 가이드선은 편집 단위와 독립적으로 확대 배율에 따라 자동으로 선택됩니다.
- 100%에서는 8분음표 선까지 표시합니다.
- 200% 이상에서는 32분음표 선까지 표시합니다.
- 화면에는 64분음표 가이드선을 그리지 않지만 노트 편집과 MIDI·MusicXML 가져오기에서는 64분음표 단위를 사용할 수 있습니다.
- 확대 배율은 `30%`, `45%`, `60%`, `85%`, `100%`, `150%`, `200%`, `350%`, `500%`입니다. 500%에서는 64분음표 위치를 점선 가이드로 추가 표시합니다.
- 상단 `배율` 버튼을 누르면 짧은 단계형 수직 슬라이더가 열리며 `-`, `=` 단축키도 유지됩니다.
- 피아노롤 위에서 `Shift + 마우스 휠`을 사용하면 마우스 커서 아래 위치를 기준으로 한 단계씩 확대·축소합니다. 선택 노트의 볼륨 조절은 기존처럼 `Alt + 마우스 휠`을 사용합니다.
- 확대·축소는 현재 보이는 피아노롤의 중앙을 기준으로 합니다.

기본 음계 간격은 `12px`입니다. Google OAuth와 실제 다국어 번역 연결은 아직 구현 전이며 UI 자리만 마련되어 있습니다.

## 주요 단축키

- `1`~`7`: 온음표, 2·4·8·16·32·64분음표 편집 단위
- `-`, `=`: 축소·확대
- 피아노롤에서 `Shift + 마우스 휠`: 커서 위치 기준 단계별 축소·확대
- 편집 채널에서 노트 선택 후 `Alt + 마우스 휠`: 선택 노트 `V0~V15` 볼륨 조절
- `Space`: 재생·정지
- `Shift + A`: 현재 편집 채널의 모든 노트 선택
- `Ctrl/Command + C`: 선택 노트 또는 현재 편집 채널의 노트 데이터 복사
- `Ctrl/Command + X`: 선택 노트 또는 현재 일반 채널 노트 데이터 잘라내기
- `Ctrl/Command + V`: 일반 채널의 빨간 재생선 위치에 붙여넣기
- `Delete` / `Backspace`: 선택한 일반 노트 삭제
- `Ctrl/Command + Z`: 되돌리기
- `Ctrl/Command + Y` 또는 `Ctrl/Command + Shift + Z`: 다시적용
- `Ctrl/Command + O`: 통합 불러오기 (프로젝트·MML/3MLE/MMI·MIDI/MusicXML)
- `Ctrl/Command + S`: 프로젝트 저장

키보드가 없는 환경에서도 상단 메뉴, 채널 버튼, 드래그, 길게 누르기 메뉴만으로 주요 기능을 조작할 수 있습니다.

### 채널 목록과 불러오기

- 왼쪽에는 `편집`/`원본 자료` 같은 구역 제목을 두지 않고 모든 편집 채널을 한 목록으로 표시합니다.
- MIDI·MusicXML에서 선택한 악기는 불러오기 확정과 동시에 일반 편집 채널이 되므로 별도 원본 루트·읽기 전용 악기 항목·채널 복사 단계가 없습니다.
- 예전 버전의 프로젝트나 자동 저장에 MIDI/MusicXML 원본 자료가 남아 있으면 열 때 일반 편집 채널로 자동 변환합니다.

### Recent visual/editing refinements
- New channels cycle through a 12-color 30° hue palette; the same palette is offered from channel/source color controls.
- MIDI instrument labels include their GM program number (1-128; drums use Ch10).
- The timeline is taller, while tempo dragging is restricted to the tempo label itself so playhead dragging remains easy.
- Alt+wheel zoom anchors under the mouse pointer; direct zoom selection anchors at the piano-roll left edge.
- Scrubbing the playhead previews every note sounding at the current beat.

- 노트를 새로 배치하거나 이동·길이 조절 중에는 우클릭으로 현재 조작을 취소할 수 있습니다. `Esc`와 동일하게 편집 시작 전 상태로 복원됩니다.
- 왼쪽 채널 목록에서 이미 선택된 편집 채널을 다시 누르면 채널 선택이 해제됩니다.

## 추가 편집 규칙 (2026-08)

- 원본 MIDI/MusicXML 악기를 편집 채널로 복사할 때 같은 악기에서 분리된 단선율 채널들은 동일한 채널 색상을 사용합니다.
- 편집 채널 악기 선택에는 `Drums (GM Channel 10)` 항목이 포함됩니다.
- 노트 생성/이동/길이 조절 중 시간축 0번, 다른 노트의 시작·끝 경계, 편집 중인 노트의 원래 시작·끝 위치를 편집 격자보다 우선하는 자석점으로 사용합니다. 예를 들어 1/4 편집 중에도 원래 1/8 길이로 정확히 되돌릴 수 있고, 다음 노트가 1/16 뒤에 시작하면 1/4 격자를 건너뛰기 전에 그 시작점에 먼저 걸립니다. 빈 구간이 현재 편집 단위보다 짧으면 새 노트의 초기 길이도 그 빈 구간까지만 생성됩니다.
- 상단 배속 오른쪽의 `🎼` 버튼은 마디 단위 공간 편집, `♩` 버튼은 박자 단위 공간 편집입니다. 빨간 재생선 위치를 기준으로 편집 채널과 편집 템포에 빈 시간을 추가하거나 시간을 삭제합니다. 원본 MIDI/MusicXML/오디오 참조는 이동하지 않습니다.
- 배율 슬라이더는 30%~500%의 지정 단계로 동작하며 500%에서는 64분음표 점선 가이드를 표시합니다.


### 원본 제목 및 삭제

- MIDI·MusicXML 원본 루트를 선택하면 제목만 수정할 수 있습니다. 원본 하위 악기/채널 이름은 읽기 전용입니다.
- 오디오 원본 제목도 정보 영역에서 수정할 수 있습니다.
- `＋ 채널` 오른쪽 휴지통 버튼은 삭제할 편집 채널을 체크박스로 고르는 다중 삭제 팝업을 엽니다. 전부 삭제한 경우 빈 채널 1개를 자동으로 생성합니다.
- 원본 하위 악기/채널을 선택한 상태에서 휴지통을 누르면 원본 문서 전체가 아니라 해당 채널 정보만 삭제됩니다. 원본 루트를 선택한 상태에서 휴지통을 누르면 문서 전체를 삭제합니다.

- MIDI/MusicXML 통합 불러오기 팝업은 제목 아래의 내부 섹션 구분선을 없애고 하단 액션 바 높이를 최소화했습니다.
- 피아노롤 노트 외곽선은 각 채널의 노트 색상을 기준으로 더 어두운 색을 자동 계산해 표시합니다.
- 설정 > 볼륨 표시에서 `모두 표시 / 선택 채널만 / 표시 안 함`을 선택할 수 있으며 기본값은 모두 표시입니다.
- 350% 이상에서는 64분음표 보조선을 점선으로 표시합니다.


### 채널 표시·음소거·복사 보정 (2026-08-11)

- 채널 목록의 표시/숨김 버튼이 실제 `visible` 상태와 피아노롤 렌더링에 즉시 반영되도록 수정했습니다.
- 채널 음소거 버튼이 실제 `muted` 상태와 재생 스케줄러에 즉시 반영되도록 수정했습니다. 재생 중 음소거를 바꿔도 전체 재생을 정지하거나 다시 시작하지 않고 해당 채널의 예약 음만 정리/복구합니다.
- 다른 채널로 이동해 채널 버튼에 포커스가 있는 상태에서도 `Ctrl/Command + C/X/V`가 동작하도록 보완했습니다.
- 다른 채널에 붙여넣을 때 대상 채널의 기존 노트와 겹치면 직접 편집과 같은 덮어쓰기 규칙으로 기존 노트를 잘라내거나 제거합니다.
