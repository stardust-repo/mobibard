# 벨로 스크립터 (VeloScriptor)

MIDI 파일과 같은 연주를 렌더링한 오디오 파일을 브라우저에서 비교해 각 Note On 이벤트의 Velocity를 다시 계산하는 독립 페이지입니다.

## 화면 구성

1. **파일 불러오기** — MIDI와 동일 연주 음원을 선택합니다.
2. **볼륨 분석** — 필요하면 오디오 시작 오프셋을 맞춘 뒤 분석합니다.
3. **MIDI 다운로드** — 분석 전부터 항상 표시되며, 분석 완료 후 결과 그래프와 MIDI 다운로드·미리듣기 기능이 활성화됩니다. 비교 슬라이더는 왼쪽이 MIDI, 오른쪽이 원본입니다.

## 동작 원리

1. 표준 MIDI Format 0/1의 트랙, 템포, 채널 이벤트와 Note On 바이트 위치를 읽습니다.
2. 오디오를 브라우저의 Web Audio API로 디코딩하고 16 kHz 모노 분석 신호로 변환합니다.
3. 각 음표 시작 시각 주변에서 기본음과 최대 4개 배음의 Attack 에너지를 측정합니다.
4. 이미 울리고 있던 동일 주파수 성분을 시작 직전 구간으로 감산합니다.
5. 악기/채널별 음량 분포와 음역별 주파수 응답 차이를 정규화해 1~127 Velocity로 변환합니다.
6. 원본 MIDI의 메타 이벤트, 템포, 트랙, Program, CC, Note Off 등은 그대로 두고 Note On Velocity 바이트만 교체합니다.

## 설정

사용자가 조절하는 분석 설정은 **오디오 시작 오프셋** 하나뿐입니다. MIDI와 오디오의 앞부분 시작 시각만 다를 때 밀리초 단위로 맞춥니다. 오디오가 늦으면 양수, 빠르면 음수입니다.

나머지 분석 기준은 자동 처리합니다.

- 기준 Velocity: 96
- 다이내믹 정규화: 100%
- CC7·CC11 중복 보정: 사용

## 보존 및 제한

- 채널 10 드럼은 음계 주파수 분석 대상에서 제외하고 원본 Velocity를 유지합니다.
- MIDI와 오디오는 같은 템포와 같은 편곡이어야 합니다. 서로 다른 템포, 루바토, 반복 구조는 오프셋만으로 맞출 수 없습니다.
- 오디오의 절대 음량은 마스터링에 따라 달라지므로 절대 dB를 Velocity로 직접 복사하지 않고 곡 안의 상대적인 세기를 자동 정규화합니다.
- 브라우저가 디코딩할 수 있는 오디오 코덱만 사용할 수 있습니다.
